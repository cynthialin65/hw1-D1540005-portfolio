Research / Projects

Research Focus — AI-assisted Engineering BOM Cost Accounting

本專案以新產品導入（NPI）為情境，將工程 BOM、原物料採購價格、PCB 與其他半成品成本、製造與人工成本等資料整合，建立簡化的多階 BOM 成本核算示範。

本作業版本刻意維持簡單：Input 1 匯入 BOM → 判斷階層；Input 2 匯入單價 → 依料號對應；最後進行 Cost Roll-up。

A simple two-input demo for NPI cost accounting. First import the BOM to determine the parent-child hierarchy; then import the unit-price Excel file to attach prices to the BOM items. The system rolls up cost from lower-level components to the top-level product and shows a simple audit result.

Input 1 — BOM 階層資料

Excel 欄位：BOM.SN、主件料號、副件料號、單位用量、料品說明。系統會依「父(主)件 → 子(副)件」自動建立階層。
